# gfss

Репозиторий учебных работ PULEMEN. В корне находится сайт Tech Academy с онлайн-курсами.

## Лабораторная работа № 3

Дисциплина: Основы облачных технологий.
Группа: ДОТ ИСР-262.
Вариант № 1: Каталог облачных сервисов.

Цель: подготовить краткий каталог IaaS, PaaS и SaaS и пройти рабочий процесс GitHub через задачи, ветви, коммиты и Pull Requests.

## Участник и роли

- PULEMEN - владелец репозитория, автор документации и исполнитель всех трёх задач.
- Формат выполнения - индивидуальный. Других участников нет.

## Ограничение индивидуального выполнения

Взаимное review другим студентом и исправление после его комментария не выполнены. Собственная проверка файлов не заменяет проверку другим участником. Эти пункты командного задания требуют участия ещё одного студента либо согласования индивидуального формата с преподавателем.
